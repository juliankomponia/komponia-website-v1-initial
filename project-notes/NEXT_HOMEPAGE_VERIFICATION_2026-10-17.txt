NEXT.JS HOMEPAGE — IMPLEMENTATION AND VERIFICATION
17 October 2026

Scope
Replaced the active homepage and site frame after the user's rejection of the
previous design. Migrated Vite/HashRouter to Next.js 16 App Router while retaining
existing subpage content, original marks, media provenance and historical designs.
Tailwind CSS and shadcn/ui provide the underlying styling and interactive controls.
The extensive design prompt was saved before implementation in
NEXT_HOMEPAGE_DESIGN_BRIEF_2026-10-17.txt.

Design decisions
Large isolated component image, short Sora headline and a clear inquiry action.
Open service links, an interactive component explorer, engineering accordion,
Komponia Lab and a four-step recurring supply explanation replace repeated cards.
Brand colors and original wordmarks follow the Komponia design system. Existing
illustrative images are described as illustrations; no new reference customers,
metrics, certifications or manufacturing ownership were invented.

Anti-slop skill
Project-local .agents/skills/kill-ai-slop from yetone/kill-ai-slop, pinned to
f6e2ae32b30443ec7bd0da4da971ee18d8f8ffcb, with upstream license and source note.
Initial scan: 101 source files, 76 candidate hits in 12 groups, manually triaged.
Final homepage scan: 2 files, 2 hits in group 11. These are the responsive 78px and
56px declarations for the deliberately short five-word hero heading, not long
sentence headlines. They are retained. These scans have different scopes and
are not presented as a numerical measure of design quality.

Issues found and fixed during review
Inactive category text contrast improved using the existing muted brand token.
Mobile Sheet made scrollable with non-shrinking content on short screens.
Duplicate header skiplink removed; the layout provides one skip link.
Dark monochrome footer wordmark rendered as a white silhouette on Ink.
Next image priority prop updated to the installed version's preload API.
Next smooth-scroll HTML attribute added to avoid route-transition warnings.
Dev origin mismatch resolved for 127.0.0.1. Before correction, Next returned 403
for development scripts when opened through that address; after correction all
18 inspected script resources return 200 and browser interactivity is confirmed.
